# 01 · 问题形式化：信息边界与 SL 规则

> 本文是整个项目的**规格说明书**。其余文档都是它的实现。

## 1.1 两条正交的约束

| 约束 | 内容 |
|---|---|
| **A · 信息约束** | agent 能看到的信息 = 人类玩家能看到的信息。不多，也不少 |
| **B · 玩法约束** | 训练 **SL**（save-load，允许重开）；但**重开是获取牌序的唯一渠道**，禁止从内存/RNG 状态直接读取 |

约束 A 决定观测与网络结构；约束 B 决定环境语义与训练流程。两者必须分开实现、分别测试。

## 1.2 信息合法性判据：三级分类

**核心澄清："随机数"本身不是禁忌，"未揭示"才是禁忌。**

| 级别 | 定义 | 例子 | 是否允许进入策略输入 |
|---|---|---|---|
| **L1 · 固定知识** | 不随 run 变化，或人类可稳定记忆/复现的确定性内容 | 卡牌数值与效果、怪物 AI 模式、**敌人当前意图**（屏幕上直接显示）、地图结构、遗物效果、关键词规则 | ✅ **允许，且允许编码进模型权重（=记忆）** |
| **L2 · 已揭示的随机结果** | 已经发生、并且已经展示过的随机结果 | 本次战斗已经抽到的牌、已经掉落的物品、已经结算的事件结果 | ✅ 允许 |
| **L3 · 未揭示的随机结果** | 已确定但尚未展示，或尚未生成的随机结果 | **抽牌堆剩余顺序**、未来掉落表、敌人未来行动队列、随机目标的预掷结果、洗牌种子 | ❌ **禁止直接读取**；只能通过观察获得（含重开后的再观察） |

判据一句话：

> 一个变量只要**要么屏幕上展示过，要么是人类可稳定记忆的确定性知识**，就可以进入策略输入；否则不行。

**注意 L1 的宽松是有意的**：人类高手脑内就存着"这只怪第一回合必上 buff""这张牌在 A10 的数值是 X"。把这些编码进权重是**记忆**，不是**作弊**。RNG 状态不是"知识"，它是"还没翻开的底牌"。

## 1.3 SL 与 NoSL：两种合法玩法

尖塔社区有两种对局规范：

| 规范 | 洗牌顺序 | 局内重开 | 流行度 |
|---|---|---|---|
| **NoSL** | 不知道未来牌序 | 不允许 | 竞技/强度认证的标准 |
| **SL** | 可以通过重开**逐步观察**出牌序 | 允许 | 大多数普通玩家的实际玩法 |

**本项目训练 SL。** 这不是偷懒——SL 是一个有明确规则、有大量真实玩家的博弈形态，而且它把"信息获取"变成了一个**主动决策**，比 NoSL 更有研究价值。

### SL 的语义前提（必须实机确认）

SL 之所以成立，是因为**存档/读档会恢复随机数状态**，而不是重掷。于是：

- 同一个节点，重开 N 次，**面对的是同一副牌序**
- 玩家第一遍打的时候看到了抽牌顺序，重开后可以基于**已知牌序**重新规划
- 这正是 SL 玩家在做的事：打一遍 → 看到牌序 → 重开 → 打得更好

> ⚠️ **这是 StS1 的社区共识，StS2 必须实测确认**，见 §1.8。如果 StS2 改成重掷，整个 SL 训练目标就变成另一件事（"重开刷牌序"），本文与 `docs/04` 都要改。

## 1.4 meta-episode 形式化（本文的核心）

SL 引入了普通 MDP 没有的结构：**同一个隐藏状态被多次尝试**。

```
MetaEpisode(节点 s₀, 隐藏状态 h, 重开预算 K):
    knowledge ← ∅
    for i = 1 … K:
        τᵢ ← rollout(从 s₀ 开始, 隐藏状态固定为 h,
                    策略 π(· | 可见状态, knowledge))     # knowledge 只含合法观测
        knowledge ← knowledge ∪ reveal(τᵢ)              # 只并入"已展示"的部分
        if 元决策模块选择接受 τᵢ 的结果:
            return τᵢ 的结果
    return τ_K 的结果
```

三个关键性质：

1. **h 在所有 attempt 中保持不变**。这是 SL 语义，由环境的 `restore` 实现——**restore 必须保留隐藏 RNG 状态，不能重掷**。这是最容易写错、后果最严重的一处（见 §1.6）。
2. **knowledge 只由合法观测构成**。跨 attempt 的知识来自"上一遍看到过什么"，与人脑的记性完全同构。
3. **重开是有代价的决策**，不是免费的。代价是算力（真实玩家那边是时间），所以存在预算 K。

### 于是策略要回答三个问题

| 层级 | 问题 | 决策频率 |
|---|---|---|
| 战斗内 | 这一手怎么打（给定已知信息） | 高 |
| 元决策 | **什么时候重开**（打得不好就重开？还是接受？） | 中 |
| 预算 | 重开几次值得（多一次尝试的边际收益 vs 算力） | 低 |

**"什么时候重开"是一条独立的策略头**，与战斗策略头并列。这是 SL 训练与 NoSL 训练最大的结构差异——很多人会漏掉它。

## 1.5 取值目标：不是一个标量，而是一族

因为有预算维度，目标是一族曲线而不是一个数：

| 指标 | 定义 | 用途 |
|---|---|---|
| **固定预算胜率** | K 次重开预算下的通关率 | 主指标（K=1 表示不允许重开） |
| **重开效率** | 达到目标胜率所需的最小期望重开次数 | 效率指标（人也不会重开 50 次） |
| **K=1 胜率（NoSL 等价）** | 不允许重开时的胜率 | ⭐ **最严格的泛化测试**——检验有多少实力来自重开知识 |
| 重开决策质量 | 重开决策与"事后最优重开决策"的一致率 | 诊断元策略 |

> **K=1 胜率是本项目最有说服力的数字。** 一个 SL 训练的 agent 如果在 NoSL 规则下依然能打，说明它学的是牌理而不是"刷牌序"。如果 K=1 胜率跌到 0，说明它只会背牌序，那不是我们要的东西。

## 1.6 反作弊判据（更新版）

判据升级为：

> **O 必须是"可见历史"的函数，且对"尚未揭示的隐藏变量"不变。**

| # | 测试 | 做法 | 抓什么 |
|---|---|---|---|
| 1 | **投影不变性** | 构造 (S₁,S₂)：**已揭示历史完全相同**，隐藏变量不同 → `observe(S₁) == observe(S₂)` 逐位相等 | 未揭示信息混进 O |
| 2 | **重开语义测试** ⭐新 | 在 s₀ 用同一动作序列跑两次（中间 restore），断言**每次抽牌结果完全相同** | restore 时重掷了 RNG → SL 语义被破坏 |
| 3 | **影子对局** | 同可见历史、不同隐藏 RNG → 策略动作序列逐位相同 | 行为级泄漏 |
| 4 | **归因测试** | 扰动每个隐藏字段，logits 变化必须恒为 0 | 定位到具体泄漏字段 |
| 5 | **种子不可见** | 字节级扫描 O，禁止出现种子及其派生物 | 种子记忆 |
| 6 | **预算审计** | restarts 计数由环境强制，策略无法绕过 K | 无限重开 |
| 7 | **真机字段白名单** | 桥接层只允许读取白名单字段（§1.7） | 真机侧泄漏 |

**测试 2 是 SL 训练特有的、也是最容易漏掉的。** 如果模拟器的 `restore` 重掷了 RNG，agent 会学到"重开可以刷到好牌序"——这条策略在真机上根本不存在（真机保留 RNG 状态），训练结果全是假的。

**测试 1 的更新同样重要**：旧版是"O 对隐藏变量不变"，在 SL 下这句话太强了——因为跨 attempt 的知识**确实**携带了隐藏状态的信息（这是合法的）。正确的表述是"对**尚未揭示**的部分不变"。

### 一个必须接受的推论

SL agent 最终会**部分地知道**隐藏状态（通过重开观察）。所以不能用"它怎么知道牌序的"来判作弊，只能用"它有没有走非观察渠道"来判。这就是为什么测试 1/3/4 的构造必须是"**可见历史相同、隐藏变量不同**"，而不是简单的"隐藏变量不同"。

## 1.7 真机对接的字段白名单（高风险）

社区 mod（STS2MCP 类）暴露的是**游戏内部状态**，它很可能包含 L3 级别的未揭示信息——完整抽牌堆顺序、敌人行动队列、预掷结果。

**因此真机路径必须做字段过滤，不能直接把 mod 的状态当观测：**

```
mod 状态 (可能含 L3)  →  [白名单过滤]  →  Observation (只含 L1/L2)
```

白名单本身需要测试：把模拟器在相同局面下产出的 Observation 与真机过滤后的结果对比，必须一致。**这是 sim2real 一致性的又一个前提**——两边连"看到的东西"都不一样，动作一致率就无从谈起。

**同时，白名单是一份"人类可见性"的声明文件**，它应该被维护成显式的、可审查的清单（参考文献 `docs/02` §2.5 的验证流程）。

## 1.8 待实测确认（最高优先级）

| # | 问题 | 怎么测 | 影响 |

## 1.9 为什么这套设计同时解决了 sim2real

真机迁移失败通常有两个原因：模型看到的是模拟器特有的信息（真机没有），或模型依赖模拟器特有的数值偏差。

本设计对第一条是**结构性免疫**的：观测被定义为"人类可见信息"，而人类可见信息在模拟器和真机上**是同一份东西**。只要白名单（§1.7）与投影函数（§1.6）正确，agent 在两个环境里看到的就是同一个信息集，**唯一的差距只剩数值精度**——而那是可以用对拍测试压到很小的。

这也是为什么值得在这套形式上花力气：它把"不可验证的玄学"变成了"可以写测试的工程"。
