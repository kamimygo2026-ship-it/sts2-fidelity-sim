## 为什么归档而不是删除

* 仓库**不是 git 仓库**，删掉就找不回来了。
* 这些文档里的"当时为什么这么判断"有独立价值：新文档会写结论与取舍，
  但不会保留每一次探针的原始输出与中间推理。

## 归档文档的阅读方式

* **只读结论 → 读新文档**（`docs/12` / `docs/13`）。归档里的完成度数字**一定**是过期的。
* **想复核某个判断当时怎么来的 → 读归档**，但要用源码或当前工具重新验证一遍。
