```python
from sts2_sim import RunEnv, RunBot

env = RunEnv(seed=7, attempt_budget=64)
bot = RunBot()
step = env.reset()

while step.phase not in ("won", "lost"):
    print(env.render_text())
    action = bot.act(step)
    step, reward, done, truncated, info = env.step(action)
    if done:
        break
    if info["hp"] < 20 and env.attempts_left:
```

## 本轮抓到的 bug（值得单独记一笔）

**症状**：区分度测试发现随机策略也 100% 通关——harness 完全没有区分度。

**根因**：`core._apply_effects` 把效果目标**永远解释成"敌人列表里的某一个"**。
怪物攻击时 `target_index=0` 指向 `state.enemies[0]`，于是**怪物打的是自己**；
红虱的"施加虚弱"也施加给了自己。玩家因此永不掉血。

**为什么 22 个测试都没抓到**：它们断言的全是"不变量"（HP 非负、卡牌守恒、能跑完）
和"基线能赢"。怪物自己打自己完全满足这些断言。

**抓出它的那条测试**：

```python
# 随机策略不该和规则 bot 打平
self.assertGreater(rule_floor - random_floor, 2.0)
```

修好之后，同一个 harness 的数字从"全员 100% 通关"变成了
"规则 bot 27% / 平均 7.2 层，随机策略 0% / 平均 1.8 层"——**这才是一个能用的 harness**。

**教训**：`docs/08` 之前写的那条"每个证明都要配反向验证"，这里得到了实证——
一个只能证明"程序没崩"的测试套件，价值接近于零。**测试必须能分辨好坏，而不只是分辨对错。**

## 测试证明了什么，没证明什么

### ✅ 已经证明（有测试）

| 机制 | 测试 |
|---|---|
| 隐藏信息变化时，观测**逐字节不变** | `test_hidden_reroll_does_not_change_observation` |
| 未进入的节点内容不影响观测 | `test_unvisited_node_contents_do_not_affect_observation` |
| 地图阶段不泄漏遭遇/事件/遗物内容 | `test_encounter_ids_absent_from_map_phase_observation` |
| 抽牌堆的**顺序**不进入观测 | `test_pile_order_is_not_in_observation` |
| **重开面对同一副牌序**（战斗层 / Run 层） | `test_restart_faces_identical_shuffle` 等 3 条 |
| 上一条**有鉴别力**（故意重掷则轨迹必变） | `test_reroll_changes_trajectory_proving_the_test_has_power` |
| **每条抽取只消费自己那条 RNG 流** | `TestRngStreamIsolation` 6 条 |
| 种子及其派生物不出现在观测里 | `test_seed_never_appears_in_observation` 等 |
| 策略模块**在语法层面**够不到隐藏信息 | `test_no_forbidden_identifiers_in_policy_modules`（AST 扫描） |
| 重开预算由环境强制 | 战斗层与 Run 层各一条 |
| 非法动作被拒绝 | 战斗层与 Run 层各一条 |
| **harness 能分辨好坏策略** | `test_rulebot_substantially_beats_random_policy` ⭐ |
| 卡牌守恒 / HP 边界 / 随机策略也会终止 | `test_selfplay_never_violates_invariants` 等 |
| 同种子完全可复现（含两种内容模式） | `test_replay_is_deterministic` 等 |

### ❌ 没有证明（诚实声明）

| 事项 | 为什么没证明 |
|---|---|
| 数值与真机一致 | **完全没验证**。伤害顺序、AI 权重、遭遇表、地图权重都是近似值 |
| 观测字段与真机 UI 一致 | 白名单尚未与真机比对（`docs/01` §1.7） |
| 策略网络不会泄漏 | 骨架里没有神经网络。AST 测试只保证**当前**的 bot 模块干净 |
| 吞吐够用 | 3.6k 决策/秒 vs 50k 目标，差一个量级 |
| SL 的语义前提成立 | **待你跑 `tools/saveload_probe.py`**（`docs/01` §1.8） |

## 文件地图

```
sts2_sim/
  rng.py       10 条命名 RNG 流，主种子哈希派生。只在 Hidden 内部存活。
  content.py   卡牌 / 怪物 / 遭遇 / 遗物 / 事件 / 进阶表 + lint()
  core.py      战斗引擎：Hidden / Snapshot / 动作掩码 / 结算 / step
  observe.py   ⭐ 唯一投影出口。Observation 与 RunObservation 均为 frozen+slots。
               含"规范化牌组槽位"——动作下标必须定义在观测空间，不能是内部存储下标。
  env.py       战斗层 SL 环境：meta-episode、重开预算、跨试次知识累积
  mapgen.py    地图生成（结构 L1 可见，内容 L3 隐藏）
  run.py       Run 层状态机 + 节点级 SL 重开 + content_mode 开关
  bot.py       战斗基线（AST 门禁：够不到隐藏信息）
  runbot.py    Run 层基线（选牌启发式 + 路线决策）
tests/
  test_anticheat.py  战斗层反作弊（7 项）
  test_sim.py        战斗层不变量 / 基线 / 吞吐
  test_run.py        Run 层：地图、RNG 分流、隔离、重开、区分度、吞吐
tools/
  saveload_probe.py  真机实验：save-load 是否保留洗牌结果
```
